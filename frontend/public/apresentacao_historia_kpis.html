A topologia corporativa no Google Cloud separa rigorosamente fontes, ingestão, lakehouse colunar, computação serverless e interfaces C-Level:

PRODIST (28.8MB), MMGD (100.7MB), Tarifas (84.9MB), Ouvidoria e IASC.
ONS Hidrologia SIN
Bucket S3 público com EAR %, ENA %, CMO e despacho térmico/hidro.
CCEE Mercado
PLD Horário, GSF Risco Hidrológico, ESS e Bandeiras Tarifárias.
CVM & Banco Central
DFP/ITR auditados de 8 companhias + Selic (432) e IPCA (13522).
2. Ingestão & Orquestração Dual Zero-Cost vs Enterprise
Google Cloud Scheduler (Ativo em Produção)
10 Cron Jobs acionando endpoints com token OIDC. Custo R$ 0,00.
Cloud Composer 3 / Apache Airflow (Opção Enterprise)
DAGs prontas em pipelines/airflow/dags/ com retries e console visual.
3. Lakehouse Medallion GCS + BigQuery BI Engine
Bronze (GCS)
Arquivos brutos imutáveis particionados com ciclo Nearline/Coldline.
Silver (BigQuery aneel_silver)
Carga tipada, deduplicação via MERGE e particionamento temporal.
Gold (BI Engine 2 GB)
Tabelas analíticas pré-calculadas com latência < 200 ms in-memory.
4. Camada de Inteligência Agêntica (Antigravity+Gemini) DeepMind + Tool Kit
Antigravity com raciocínio agêntico, geração de código, self-healing e automação Dataform SQLX, aliada ao motor matemático PRORET de revisão tarifária da ANEEL.
5. Serving, Frontend & Clientes Cloud Run + React SPA

Frontend React 18 + Vite + Tailwind
